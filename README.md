# Pedra, Papel e Tesoura

Um jogo de **pedra, papel e tesoura** feito em Python para ser executado no terminal. As mensagens do jogo estão em inglês.

## Como funciona

- Você escolhe entre 1 e 5 rodadas.
- Em cada rodada, digita `1` para pedra, `2` para papel ou `3` para tesoura.
- O computador faz uma escolha aleatória.
- Ao final, o jogo mostra a pontuação e informa o campeão.

## Requisitos

- Python 3 instalado no computador.

## Como executar

1. Baixe este repositório clicando em **Code > Download ZIP**.
2. Extraia os arquivos.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python rock_paper_scissors.py
```

## Arquivo principal

- `rock_paper_scissors.py`: contém toda a lógica do jogo.

## Conceitos praticados

Este projeto utiliza entrada de dados, funções, condicionais, repetição, tratamento de erros e números aleatórios.
